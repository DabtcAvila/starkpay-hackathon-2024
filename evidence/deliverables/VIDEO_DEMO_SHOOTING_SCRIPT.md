# StarkPay iOS App - Professional Video Demo Shooting Script

## Executive Summary

**Target Duration**: 2 minutes 45 seconds  
**Objective**: Maximize hackathon scoring (80 points) by showcasing the complete, functional StarkPay iOS app  
**Format**: Professional screen recording with live narration  
**App Features**: 2,207 lines of working Swift code, biometric authentication, premium animations, payment flows

---

## Pre-Recording Checklist

### Device Preparation
- [ ] iPhone/iPad with latest iOS (recommended: iPhone 14 Pro or newer for best quality)
- [ ] StarkPay app installed and functional
- [ ] Device fully charged (recording can drain battery quickly)
- [ ] Close all other apps to prevent notifications
- [ ] Enable Do Not Disturb mode
- [ ] Set device to maximum brightness
- [ ] Clean screen thoroughly

### App State Setup
- [ ] Fresh app launch (force quit and restart)
- [ ] Ensure demo account has $1,247.83 balance
- [ ] Verify transaction history shows mock data
- [ ] Test Face ID/Touch ID functionality before recording
- [ ] Have demo payment details ready:
  - Recipient: "alice_crypto" 
  - Amount: "$25.00"
  - Note: "Coffee money ☕"

### Recording Environment
- [ ] Quiet environment with minimal background noise
- [ ] Good lighting (avoid glare on screen)
- [ ] Stable surface or tripod for device
- [ ] External microphone connected and tested (if available)
- [ ] Recording software configured (iOS Screen Recording or QuickTime)

## Detailed Shot List & Script

### SHOT 1: Splash Screen & Intro (0:00 - 0:15)
**Visual**: App launch showing premium splash screen with animated StarkPay logo
**Audio Narration**: 
> "Meet StarkPay - a lightning-fast, secure payment app designed for Starknet. With over 2,000 lines of native Swift code, this is a comprehensive iOS prototype with advanced biometric security and premium user experience."

**Technical Notes**:
- Start recording before launching app
- Allow full 3-second splash animation to play
- Show the premium black gradient background and animated logo

### SHOT 2: Biometric Authentication (0:15 - 0:30)
**Visual**: Face ID/Touch ID authentication screen, then successful unlock animation
**Audio Narration**:
> "Security is paramount. The app features industry-standard biometric authentication with Face ID and Touch ID support, plus automatic re-authentication when returning from background."

**Technical Notes**:
- Demonstrate actual biometric authentication (not simulated)
- Show the premium authentication UI with gradient backgrounds
- Ensure smooth transition to main app

### SHOT 3: Main Dashboard Overview (0:30 - 0:50)
**Visual**: Main Pay screen showing balance, quick actions, and recent transactions
**Audio Narration**:
> "The main dashboard displays your balance with smooth animations, quick action buttons for Pay and Request, and a live transaction history. Every interaction includes premium haptic feedback for an enhanced user experience."

**Technical Notes**:
- Tap the refresh button to show the loading animation
- Scroll through the transaction list smoothly
- Highlight the balance display ($1,247.83)

### SHOT 4: Payment Flow Demonstration (0:50 - 1:35)
**Visual**: Complete payment process from Pay button tap to success animation
**Audio Narration**:
> "Let's send a payment. Tap Pay, enter the recipient and amount. The app shows a real-time progress indicator with status updates. Processing includes validation, StarkNet integration simulation, and transaction confirmation."

**Technical Notes**:
- Tap "Pay" button with haptic feedback
- Fill in recipient: "alice_crypto"
- Fill in amount: "$25.00"  
- Fill in note: "Coffee money ☕"
- Tap "Pay $25.00" button
- Show full progress animation (3 seconds)

- Return to updated transaction list

### SHOT 5: Activity & Search Features (1:35 - 2:00)
**Visual**: Navigate to Activity tab, demonstrate search functionality
**Audio Narration**:
> "The Activity tab features advanced search capabilities with real-time filtering, shimmer loading states, and smooth animations. Search works across recipient names, amounts, notes, and dates."

**Technical Notes**:
- Tap Activity tab
- Demonstrate search by typing "alice"
- Show filtered results with highlighting
- Clear search to show all transactions
- Show pull-to-refresh functionality

### SHOT 6: Profile & Security Settings (2:00 - 2:25)
**Visual**: Profile tab, tap Security settings, show biometric toggle

## Common Pitfalls to Avoid

### During Recording
- ❌ Don't rush through features - let animations complete
- ❌ Don't tap too quickly - show deliberate interactions
- ❌ Don't ignore loading states - they show app sophistication
- ❌ Don't skip biometric authentication - it's a key differentiator
- ❌ Don't forget to narrate what's happening visually

### Technical Issues
- ❌ Notification interruptions (enable Do Not Disturb)
- ❌ Low battery warnings during recording
- ❌ Screen timeout during long explanations
- ❌ Audio/video sync issues
- ❌ Inconsistent app state between takes
