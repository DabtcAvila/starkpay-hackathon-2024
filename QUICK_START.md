## 📱 Run the iOS App

### Prerequisites (1 minute)
- **macOS computer** (required for iOS development)
- **Xcode 15+** installed (free from Mac App Store)
- **No developer account needed** (app runs in simulator)

### Steps (1 minute)

1. **Open the project:**
   ```bash
   cd StarkPay-Hackathon-Submission/StarkPayiOS
   open StarkPayiOS.xcodeproj
   ```

2. **Select simulator:**
   - In Xcode: Product Menu → Destination → iPhone 15 Pro (or any recent iPhone)

3. **Build & Run:**
   - Press `▶️` button in Xcode (or `Cmd+R`)
   - App builds automatically and launches in simulator

4. **Experience the app:**
   - **Splash screen:** Premium animated intro (3 seconds)
   - **Main interface:** Instagram/Venmo-style payment app
   - **Try features:** Tap Pay, browse Activity, check Profile

## 🎯 What to Look For

### 1. **Premium Polish** (Immediate impression)
- **Splash Animation:** Rotating lightning bolt with glow effects

- **Smooth Transitions:** No jank, professional-grade animations

### 2. **Familiar UX** (Core innovation)
- **Zero Crypto Jargon:** No wallet addresses, gas fees, or blockchain terms
- **Social Elements:** Send money to @alice, not 0x742d35Cc6...
- **Instagram-Style Interface:** Tabs, cards, familiar navigation patterns

### 3. **Technical Excellence** (iOS development quality)
- **Face ID Integration:** Real biometric authentication (try it!)
- **Native Performance:** SwiftUI, no web views or cross-platform compromises
- **Production Code:** Clean architecture, proper error handling

### 4. **Payment Flow** (Core functionality)
- **Send Money:** Tap Pay → enter @username → amount → send
- **Transaction History:** See all payments in Activity tab
- **Profile Management:** User settings and preferences

## 🚨 Troubleshooting

### App Won't Build?
- **Xcode version:** Requires Xcode 15+ for iOS 17 support
- **Clean build:** Product → Clean Build Folder, then rebuild
- **Simulator issues:** Try different iPhone model in simulator picker

### Can't Run Xcode?
- **Mac required:** iOS development only works on macOS
- **Alternative:** View source code directly in [`StarkPayiOS/StarkPayiOS/`](StarkPayiOS/StarkPayiOS/)
- **Screenshots:** Check [`assets/screenshots/`](assets/screenshots/) for visual demo
