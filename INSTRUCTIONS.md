# 🚀 StarkPay Lightning - Demo Instructions

## 📱 **HOW TO RUN THE APP**

### **Requirements:**
- macOS with Xcode 15.0+
- iOS Simulator or iPhone with iOS 17.0+

### **Steps:**

1. **Open Project:**
   ```bash
   open StarkPayiOS/StarkPayiOS.xcodeproj
   ```

2. **Select Target:**
   - iPhone Simulator (recommended) 
   - Or connected iPhone

3. **Build & Run:**
   - Press ▶️ in Xcode
   - Or press ⌘+R

4. **Experience the App:**
   - Watch premium splash screen (3 seconds)
   - Navigate Pay/Activity/You tabs
   - Test payment flow
   - See transaction history
